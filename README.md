# Research Proposals

Static site (GitHub Pages) hosting two research proposals:

- [Quantifying Tactical Erosion](tactical-erosion.html) — an ML approach to
  predicting the decay of positional integrity and physical efficiency in
  elite football match-play.
- [Automating Risk: FIFA-Approved Skeletal Tracking](fifa-biomechanics.html) —
  validating FIFA's SAOT skeletal tracking against Vicon motion capture to
  build an explainable AI injury-risk dashboard.

Plain HTML/CSS, no build step. Served from the repo root via GitHub Pages.
